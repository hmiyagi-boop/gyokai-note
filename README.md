# 業界理解ノート

コンサル・営業支援で、お客様と共通認識を持って話すための「業界の一般常識」学習アプリです。

## できること

| 画面 | 内容 |
|---|---|
| 業界図鑑 | 業界ごとの儲けのしくみ・利益率・売上規模・拠点数・最近の動き・用語 |
| 業界比較 | 利益率・拠点数・売上規模を業界横断で並べ替えて比較 |
| 売上ものさし | 「売上○億円」がその業界で小規模／中堅／大手のどれかを判定 |
| 業種→業界 | 「SES」「調剤薬局」などの業種が、どの業界に分類されるかを検索 |
| 架電トーク | 業界の構造 → 採用課題 → 経営への影響、の仮説とトーク例 |
| クイズ | 上記の知識からランダムに出題 |
| 用語集 | 共通の経営用語と業界別の用語を検索 |

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけで動きます（インストール不要）。

## 業界・知識を追加するには

`data/industries.js` を編集します。既存の業界をコピーして中身を書き換えるのがいちばん簡単です。
数値は会話のための目安です。出典（法人企業統計、業界団体の調査、上場企業の決算資料など）を確認して更新してください。

## ファイル構成

```
index.html          画面の骨組み
style.css           見た目
app.js              動き（タブ切り替え、クイズの出題など）
data/industries.js  業界データ（ここを育てていく）
docs/GITHUB_GUIDE.md  GitHubの使い方メモ
```
