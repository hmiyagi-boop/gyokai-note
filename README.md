# 業界理解ノート

コンサル・営業支援で、お客様と共通認識を持って話すための「業界の一般常識」学習アプリです。
PC・スマホの両方で使えます（スマホはホーム画面に追加するとアプリのように使えます）。

## できること

| 画面 | 内容 |
|---|---|
| 業界図鑑 | 市場規模・儲けのしくみ・コスト構造・利益率・KPI・法律/制度・大手企業・最近の動き、経営課題の仮説（売上／コスト／人材／DX） |
| 仮説トーク | 業界×視点を選ぶと「原因 → 起きること → 経営への影響」とトーク例を表示 |
| クイズ | 1回3問。業界知識（12種）・ビジネス基礎（財務・フレームワーク・常識）・計算問題から出題。終了後に正答率と解説 |
| 成績ダッシュボード | 正答率の推移、分野別・種類別・業界別の正答率、次に復習したい業界 |
| 業界比較 | 利益率・拠点数・売上規模を業界横断で並べ替えて比較 |
| 売上ものさし | 「売上○億円」がその業界で小規模／中堅／大手のどれかを判定 |
| 業種→業界 | 「SES」「調剤薬局」などの業種が、どの業界に分類されるかを検索 |
| 用語集 | 財務・フレームワーク・業界用語・KPI・法律を検索 |
| 使い方ガイド | シーン別のおすすめの使い方、各画面の説明、よくある質問 |

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけで動きます（インストール不要）。
スマホで使うには GitHub Pages で公開します（docs/GITHUB_GUIDE.md の Step 3）。

## 内容を更新するには

- 業界データ：`data/industries.js`（既存の業界をコピーして書き換えるのが簡単）
- ビジネス基礎：`data/basics.js`（財務用語・フレームワーク・常識問題）
- 月1回の更新手順：`docs/MONTHLY_UPDATE.md`

数値は会話のための目安です。出典（法人企業統計、業界団体の調査、上場企業の決算資料など）を確認して更新してください。

## ファイル構成

```
index.html            画面の骨組み
style.css             見た目（PC・スマホ両対応）
app.js                図鑑・比較・トークなどの画面
quiz.js               クイズ（出題・採点・回答履歴の保存）
dashboard.js          成績ダッシュボード
data/industries.js    業界データ
data/basics.js        ビジネス基礎データ
manifest.webmanifest  スマホのホーム画面に追加するための設定
docs/                 GitHubの使い方・月次更新の手順
```
